FIELD MANUAL / MODULE 03

How it works

Sliding windows keep up to W unacknowledged packets on the link. Both receivers deliver data in order. Their response to a gap makes the difference.

01 / GO-BACK-N

A simple receiver; a wider recovery.

ACK(n) confirms every packet ≤ n
Sender: [base … base + W − 1]
Receiver: [expected] / window = 1

One timer protects the oldest unacknowledged packet. Out-of-order DATA is discarded and the last in-order packet is re-ACKed. Timeout resends the outstanding window.

02 / SELECTIVE REPEAT

Remember arrivals; repair the gap.

ACK(n) confirms only packet n
Sender: [sendBase … sendBase + W − 1]
Receiver: [rcvBase … rcvBase + W − 1]

Each packet has an independent timer. Out-of-order DATA is buffered. When the missing packet arrives, the consecutive prefix flushes to the upper layer. Only the timed-out packet is resent.
